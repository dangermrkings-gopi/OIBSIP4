# ✨ Magic Calculator

A beautiful, interactive, browser-based calculator built using **HTML5, CSS3, and Vanilla JavaScript**.  
The project features a magical animated interface, responsive button layout, and custom arithmetic logic without using `eval()`.

---

## 🚀 Features

✅ Modern glassmorphism UI design  
✅ Animated magical background effects  
✅ Animated glowing title text  
✅ Basic arithmetic operations:
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)

✅ Numeric buttons (0–9)  
✅ Decimal point support  
✅ Clear (C) functionality  
✅ Delete / Backspace functionality  
✅ Result calculation (=)  
✅ Division-by-zero error handling  
✅ Operator chaining support  
✅ CSS Grid button layout  
✅ JavaScript event listeners (no inline onclick)  
✅ Fully browser-based (no installation required)

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
